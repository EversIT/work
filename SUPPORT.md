# Getting help

- **A question or an idea?** Use GitHub Discussions if they are enabled for this repository, otherwise open an
  issue with the _question_ label.
- **Something is broken?** Use the _Bug report_ issue form. Include the version or commit, how you run it
  (Docker or from source), and what you expected.
- **A security problem?** Never in public: see [SECURITY.md](SECURITY.md).
- **Setting it up?** Start with the [README](README.md), then [apps/docs/src/CONFIGURATION.md](apps/docs/src/CONFIGURATION.md).

This is a volunteer project; replies may take a while, and a clear, reproducible report gets the fastest answer.
